## 1. 프로젝트 소개
* **프로젝트명**: 스파이더맨 거미줄 스윙의 물리 법칙 탐구와 3D 웹 시뮬레이션 구현
* **개요**: 가상 물리 환경에서 스파이더맨의 거미줄 액션을 단순 시각 연출이 아닌 고전역학(진자 운동, 탄성력, 장력) 및 점탄성 수식 기반으로 재현한 시뮬레이터입니다. 웹 브라우저 상에서 Three.js 3D 렌더링을 통해 외력과 궤적 변화를 실시간으로 관찰하고 분석할 수 있습니다.

---

## 2. 주요 기능
* **실시간 3차원 물리 엔진 시뮬레이션**
  * Three.js 기반 가상 공간에서 고정점과 이동체 사이의 진자 운동, 구심력, 중력, 공기 저항 실시간 연산
  * 거미줄의 인장 및 점탄성 특성을 반영하여 줄이 늘어났다 수축하는 동적 궤적 구현
* **동적 파라미터 제어 (Interactive Physics Lab)**
  * Streamlit 사이드바 UI를 통해 중력가속도($g$), 발사체 질량($m$), 거미줄 탄성 계수($k$), 줄의 초기 길이($L$) 등 물리 상수를 슬라이더로 실시간 조절
* **시각화 및 궤적 트래킹**
  * 실시간 속도 벡터, 작용 장력 크기, 역학적 에너지(운동에너지 + 위치에너지) 변화 데이터 표시
  * 마우스 조작을 통한 자유로운 3D 시점 전환(OrbitControls)
* **인터랙티브 스윙 모드**
  * 키보드 입력을 통해 건물을 타깃으로 거미줄을 발사하고 추진력을 얻는 상호작용 모드

## 3. 조작 및 사용법
1. **파라미터 설정**: 좌측 조절 패널(Sidebar)에서 탐구할 물리 변수(탄성 계수, 줄 길이, 투사 각도 등)를 설정합니다.
2. **시뮬레이션 조작**:
   * **마우스 드래그 / 휠**: 3D 공간 시점 회전 및 줌 인/아웃
   * **Space Bar**: 목표 지점으로 거미줄 발사 및 진자 스윙 시작
   * **Space Bar 해제**: 거미줄 분리(Release) 및 접선 방향 포물선 운동 전환
3. **데이터 확인**: 화면 상단/측면 인디케이터에서 실시간 속도, 장력(N), 에너지 보존 수치를 확인합니다.

## 4. 시작하기 (실행 방법)

### 사전 요구 사항
* Python 3.9 이상
* 최신 웹 브라우저 (Chrome, Edge 등 WebGL 지원 브라우저)

### 설치 및 실행
```bash
# 1. 저장소 클론 및 디렉터리 이동
cd spiderman-physics-lab

# 2. 필수 라이브러리 설치
pip install streamlit

# 3. 애플리케이션 실행
streamlit run app.py
